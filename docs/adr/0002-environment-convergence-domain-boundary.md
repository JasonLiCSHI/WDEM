# Model Environment Convergence as one bounded context

WDEM models Profile definition, Task dependency planning, compliance, and Task Workflow outcomes in one **Environment Convergence** bounded context because they share one language and one consistency goal: converging a workstation to a trusted Profile. `EnvironmentProfile` is the aggregate root and owns the complete immutable Task graph; Task definitions and Workflow definitions are aggregate members, while Plan is a derived planning result and an Environment Run is Application orchestration. Profile transport/cache, Windows process execution, CLI, and WPF remain adapters around this context rather than artificial bounded contexts. New bounded contexts should be introduced only when an independently evolving model and explicit translation boundary appear.
