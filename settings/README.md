# Runtime settings

Store version-controlled configuration files used by WDEM Task Activities in this directory.

Do not commit credentials, machine-specific user settings, generated files, or Profile cache data. Runtime user settings remain under `%LOCALAPPDATA%\Wdem`.

Current configuration files:

- `.vsconfig` declares Visual Studio workloads and components.
- `CT.DotSettings` contains ReSharper settings that are merged into the current user's global settings layer.
